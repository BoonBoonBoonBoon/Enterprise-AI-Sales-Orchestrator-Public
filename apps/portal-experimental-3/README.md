# Agentic Portal Experimental 3

A third experimental site focused on **friendly, approachable B2B marketing** for teams introducing AI into their workflow.

## Design Philosophy

- **Light, warm theme** – inviting, not intimidating
- **Clear value propositions** – "save time", "stay in control", "sound like you"
- **Trust signals everywhere** – ratings, testimonials, security badges
- **Simple 3-step flow** – reduces cognitive load for busy buyers
- **FAQ section** – addresses common AI fears upfront
- **Soft floating orbs** – calming background animation (not aggressive)

## Run

```bash
cd apps/portal-experimental-3
npm install
npm run dev
```

Opens at http://localhost:3003
