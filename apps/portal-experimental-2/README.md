# Agentic Portal Experimental 2

A second, separate experimental website focused on a **high-signal marketing landing** with a **calmer architecture visualization**.

## Goals

- Keep the agent-architecture vibe
- Reduce visual intensity (less "eye-sore")
- Improve marketing clarity: value prop → proof/trust → CTA

## Run

```bash
cd apps/portal-experimental-2
npm install
npm run dev
```

Opens at http://localhost:3002
