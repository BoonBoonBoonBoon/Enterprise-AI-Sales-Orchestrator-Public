🔄 EXECUTION FLOW
═════════════════════════════════════════════════════════════════════════════════

When you call: await harness.execute(task)

1. Generate unique execution_id for tracking
2. Check quota (if enabled)
   └─ Raise QuotaExceededError if limit hit
3. Load checkpoint (if exists)
   └─ Resume from saved state if available
4. Start tracing span (if observability enabled)
   └─ Record execution_id, agent_type, etc.
5. Execute agent with retry strategy
   └─ Exponential/linear/jittered backoff on failure
   └─ Log each attempt
6. Save checkpoint (if enabled)
   └─ Store state for potential resumption
7. Record success metrics
   └─ agent.execution.success with tags
8. Return result

If error occurs:
   └─ Record failure metrics
   └─ Log error event with context
   └─ Raise exception after retries exhausted
