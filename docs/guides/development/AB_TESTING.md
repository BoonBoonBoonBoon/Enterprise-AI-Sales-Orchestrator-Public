# A/B Testing Guide

This page is a lightweight placeholder for A/B testing references inside the MkDocs site.

## Recommended Approach

- Treat variants as explicit inputs to the Copywriter/Outreach pathway.
- Persist variant metadata (campaign, template/version, cohort) via the PersistenceAgent.
- Measure outcomes in downstream systems (deliverability, reply rate, conversions).
